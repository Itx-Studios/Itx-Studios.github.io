# The ITX AI Series is getting a new Numscan model, Numscan 2

The ITX Research Department is using more and more ressources to finalize the newest Digit Classificator which not only slams older models in accuracy but also cuts production costs.
The new model will use Convolutional Technology to boost effiency and making it viable for more real-life scenarios.

Using Convolutional Neural Networks, Numscan 2 will prevent miss-scaled and poorly drawed digits using Pooling.
This will help in classifing accuratly in scenarios like misspropotions.

The release date of the model has not been shared but rumors forecast it before Christmas. ITX Studios said publicly that the AI roadmap plans no further model for primarely classifing digits. Development ressources will be relocated which a focus on more complex machine-learning models like RNNs or Transformers. The development of new Convolutional Neural Networks is also planned, using the Numscan 2 infrastructure to mark a new Era of Technology for the ITX Research Department.

Alongside Numscan 2, ITX Studios have been working on an AI editor which lets users tests AI models directly on the ITX Website. The editor will support both Numscan models and will offer infrastructure for future inventions. The release date of the editor is still unkown.
